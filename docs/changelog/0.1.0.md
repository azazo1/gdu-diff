# gdu-diff v0.1.0

gdu-diff 的首个正式版本, 提供基于 gdu-go 导出快照的磁盘占用浏览与对比 TUI, 支持历史快照保存, 当前目录重扫对比和多份快照直接比较.

## Highlights

- 保存历史 `shot` 快照, 每个目录保留 3 份最新快照, 并额外长期保留磁盘占用最低的一份
- 支持目录对比历史快照, 单份快照对比当前目录, 以及多份快照直接对比
- 展示 `Latest`, `Delta`, `Share`, `ShareD` 等指标, 可在 `disk` 和 `apparent` 两种口径间切换
- TUI 提供键盘导航, 排序切换, 标记选区汇总, 路径复制和在当前目录打开 shell 等操作
- 加载界面展示阶段进度, 并跟踪外部 `gdu-go`/`gdu` 的扫描状态

## 快照管理

- `shot` 子命令为目录生成并保存快照, 快照以 zstd 压缩存储, 后缀为 `.json.zst`
- 兼容直接读取未压缩的 `.json` 导出文件
- 支持 `-1`, `-2`, `-3` 等别名, 引用某个目录从新到旧的第 n 份历史快照
- 数据目录按目标路径安全编码分桶, 过长的路径名自动截断并追加稳定哈希

## 对比分析

- 多快照对比要求所有根目录一致, 不一致时直接拒绝进入 TUI
- 汇总当前视图目录自身的变化, 以及条目在父目录和根目录中的占比变化
- 支持只显示目录, 切换 `disk`/`apparent` 口径, 以及按名称, 大小, 变化量或占比排序
- 在包含当前扫描结果的对比模式下, 可按目录局部重扫, 不重建基线快照

## 界面交互

- `j`/`k` 与方向键移动, `,`/`.` 翻页, `g`/`G` 跳转首尾, `l`/`h` 进入或返回上级目录
- `Space` 标记条目并自动跳转下一项, 底部汇总选区的条目数, 大小和占比变化
- `c`/`C` 复制相对或绝对路径, `b` 在当前视图目录打开 shell, `?` 查看帮助
- 终端宽高不足时自动隐藏底部详情区域, 把空间优先让给列表

## 可靠性

- 修复 `gdu-go` 导出 JSON 嵌套超过 128 层时解析失败的问题
- 快照读取, 外部扫描进度采集和 TUI 事件循环均基于异步运行时, 不再依赖手写多线程轮询
